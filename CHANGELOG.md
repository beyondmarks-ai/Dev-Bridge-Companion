# Changelog

All notable changes are documented in this file.

## [Unreleased]

### Planned

- Background build notifications.
- Resumable downloads.
- Screenshot annotation, voice notes, and structured test reports.

## [0.3.0] - 2026-08-03

### Added

- Two-minute, one-use SDK handoff passed through an explicit Android launch intent.
- Automatic exchange for a separate build-scoped SDK token.
- Android 11+ historical ANR, native crash, low-memory, and process-exit collection.
- Consent-driven MediaProjection screen recording with foreground notification.
- Recording upload to protected Azure diagnostic attachments.
- SDK screenshot capture boundary and authenticated attachment upload.

## [0.2.0] - 2026-08-03

### Added

- Android `PackageInstaller` session integration with detailed failure reasons.
- Automatic APK download, verification, installation, and launch telemetry.
- Device and display context submitted during secure pairing.
- Opt-in Flutter diagnostics SDK with crash, lifecycle, route, and slow-frame capture.
- Batched diagnostic delivery with bounded retry buffering.
- SDK analysis and tests in CI.

## [0.1.0] - 2026-08-03

### Added

- Secure DevBridge QR scanning and device pairing.
- Encrypted connection credential storage.
- Remote project/app/build display.
- Authenticated APK download with progress.
- SHA-256 artifact verification.
- Android unknown-source permission and Package Installer integration.
